Document properties

Insert table

Tables are laid out by the browser and will not split across a page break — a table taller than the text box moves whole to the next page.

Insert link

Selected text becomes the link label. Leave the label blank and the address is used.

Find & replace

Replace works on the text of the document, so a match that spans a bold run and a plain one is still one match — the replacement takes the formatting of the first character it landed on.

Verse line breaks

Shift-Enter marks where a line ends. A marked line is set on its own baseline slot, ragged, and is never re-wrapped to fill the margin — that is the exemption. Only breaks go here; the words themselves are edited in DOK.

DOK — Document Object Kernel

The word processor of KADsuite. One HTML file, no build step, no server: the document never leaves the machine it was typed on.

Why the DOM. KANVAS draws text — a string at an (x, y), which is right for illustration and is why it can write a PDF by hand. A document is not that. It is paragraphs that wrap to a measure and reflow when a word changes three pages earlier. The browser already has that engine, so DOK uses it and solves only what the browser will not: cutting the endless column into sheets of paper.

Formats. .kvs maps to .svg, .kad maps to .dxf, .dok maps to .docx. The OOXML reader and writer here are written from scratch — a ZIP built on CRC32 and the browser's own deflate, and an OOXML tree walked into blocks. Nothing is fetched and nothing is uploaded.

Print is the PDF path. Deliberately. It hands the page to the operating system's text rasteriser, which is the same one a printer uses.
